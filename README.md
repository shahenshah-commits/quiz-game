# 💎 Luxury Maharthi Quiz Game

A premium, modern, and interactive quiz game built with HTML, CSS, and JavaScript. It features dynamic question shuffling, a luxury glassmorphism UI with animated moving background stars, a live-score system, and a 2-life challenge.

## 🚀 Features
* **Luxury Design:** Stunning dark-gold glassmorphism UI with smooth animated background star effects.
* **50+ Unique Questions:** Diverse trivia questions covering history, science, geography, and general knowledge.
* **Shuffle System:** Questions are randomized every time you start a new game so it never gets repetitive.
* **Live Feedback & Lives:** Features a 2-life heart system (`❤️❤️`) with instant correct/wrong visual indicators and a "Next" button progression.
* **High Score Tracker:** Saves your best score locally in your browser.
* **Monetization Ready:** Includes integrated VIP bonus direct links.

## 🕹️ How to Play
1. Open the live website link.
2. Click on **"▶ रॉयल गेम शुरू करें"** to start the quiz.
3. Choose the correct option for each question. You have 2 lives (hearts).
4. View your final score once the game ends and try to beat your high score!
